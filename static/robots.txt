# Порядок блоков здесь обратный привычному: сначала поимённые агенты, потом общее
# правило. Робот всё равно подчиняется САМОМУ ТОЧНОМУ совпадению по имени, а не первому
# сверху, так что на разбор это не влияет — зато видно, ради чего файл вообще заведён.
#
# Поимённые блоки сегодня ничего не меняют: «User-agent: *» ниже и так пускает всех.
# Они страховка на завтра. Стоит однажды дописать в общий блок любой Disallow — закрыть
# служебный раздел, черновик, копию для отладки — и вместе с ним молча отключится канал
# ответов ассистентов. Органика при этом не просядет, отчёта об этом нигде не будет,
# и заметить потерю будет не по чему. Собственный блок такую правку переживает.
